# Session Cove 用户指南

> 像素风格的 AI 编程会话管理器，住在你的菜单栏里。

---

## 这是什么？

当你用 Claude Code 写代码时，每次对话都是一个"会话"（Session）。时间长了，你会有几十个甚至上百个分散在不同项目里的会话——忘了昨天跟 Claude 聊了什么、找不到上周那个调试会话、切换项目时丢失上下文。

**Session Cove** 帮你把所有会话整理成一张"港口地图"：每个项目是一座像素小岛，点击就能看到所有历史会话，一键恢复继续对话。

---

## 安装

### 方式一：直接下载（推荐）

1. 去 [Releases 页面](https://github.com/koersliven/Session-cove/releases) 下载最新的 `.dmg` 文件
2. 打开 DMG，把 Session Cove 拖入 Applications
3. 首次打开时 macOS 会拦截，去 **系统设置 → 隐私与安全性** → 点"仍要打开"

或者终端执行：
```bash
xattr -cr /Applications/Session\ Cove.app
```

### 方式二：一键安装（从源码编译）

```bash
git clone https://github.com/koersliven/Session-cove.git
cd Session-cove
./install.sh
```

### 首次启动

启动后会自动完成：
- 在 `~/.claude/settings.json` 中注册 Hook（让 Claude 的审批弹窗走 Session Cove）
- 创建 `~/.session-cove/` 配置目录

如果你用 iTerm2，第一次恢复会话时 macOS 会弹窗问"允许 Session Cove 控制 iTerm2 吗"—— 点允许即可。

## 界面介绍

### 两种显示模式

| 模式 | 样子 | 适合 |
|------|------|------|
| **宠物模式** | 屏幕上漂浮的像素章鱼 | 喜欢桌面宠物的用户 |
| **刘海模式** | 住在 MacBook 刘海下方 | 喜欢干净桌面的用户 |

在 **设置 → 通用** 里切换。

### 章鱼的状态

你的像素章鱼会根据 Claude 的工作状态变化：

| 状态 | 表现 | 含义 |
|------|------|------|
| 💚 上下跳动 | 快速弹跳 | Claude 正在工作 |
| 💛 缓慢漂浮 | 慢悠悠 | 最近活跃过，现在闲着 |
| 🩶 几乎静止 | 半透明 | 所有会话都休眠了 |
| 🔴 急促摇晃 | 抖动 + 红点 | Claude 在等你审批！ |

### 港口地图（Harbor Map）

点击章鱼（或刘海区域）打开港口地图：

- 每个**项目**是一座小岛
- 小岛的颜色代表活跃程度（亮 = 活跃，暗 = 休眠）
- 活跃的岛有绿色气泡冒出来
- 最多显示 6 座岛，超过的点 "+MORE" 翻页

点击一座岛 → 底部出现该项目的所有会话卡片。

## 核心功能

### 1. 浏览和恢复会话

每张会话卡片显示：
- 状态点（绿/黄/灰）
- 相对时间（"3 分钟前"）
- AI 摘要（Claude 自动总结的对话内容）
- 自定义名称（如果你设了的话）
- Git 分支

**恢复会话：** 点击卡片上的 ▶ 按钮，Session Cove 会在你的终端里执行 `claude --resume`，接着上次聊的继续。

### 2. 审批弹窗

当 Claude 要执行需要权限的操作（比如运行 bash 命令、编辑文件），Session Cove 会弹出审批卡：

- **允许** — 只批准这一次
- **始终允许** — 以后同类操作自动通过
- **本次会话** — 这次对话期间自动通过
- **拒绝** — 阻止这次操作

点击"展开"可以看到 Claude 具体要执行什么命令。

### 3. 回答 Claude 的提问

当 Claude 调用 `AskUserQuestion` 问你问题时，Session Cove 弹出表单：
- 单选题 → 点选
- 多选题 → 勾选
- 开放题 → 输入文字
- 密码/Token → 加密输入框

提交后答案直接传回 Claude，你不需要切换到终端。

### 4. 任务完成通知

Claude 完成一轮工作后，弹出小提示：
- 显示完成的项目和会话名
- 可以点"打开会话"直接跳到终端
- 30 秒后自动消失

### 5. 管理会话

**重命名：** 点击卡片上的 ✏️ 图标，给会话起个好记的名字。

**删除：** 右键 → 移到废纸篓（可以从废纸篓恢复）。

**批量删除：** 点 dock 里的 "SELECT" 按钮 → 勾选多个 → 删除。

**删除整个项目岛：** 右键地图上的岛 → "Delete Island"，会删除该项目的所有会话。

### 6. 新建会话

两种方式：

**从 harbor 顶部：** 点 `+NEW` → 选一个项目文件夹 → 自动在终端启动 Claude。

**从项目 dock：** 点某座岛底部的 `+NEW` 按钮，直接在该项目目录启动。

### 7. Workspace（工作区）

如果你有一个涉及多个代码仓库的大项目（比如前端 + 后端 + 基础设施），可以创建 Workspace：

1. 点港口地图右上角的 `+Workspace`
2. 输入名称（比如 "电商项目"）
3. 选择父目录（比如 `/Users/你/Work`）
4. 添加相关仓库（它们会以快捷方式链接到 Workspace 文件夹）
5. 点 "CREATE & START"

效果：
- 在父目录下创建一个以 Workspace 命名的新文件夹
- 各仓库通过快捷方式出现在里面（Claude 能直接访问所有代码）
- 自动启动一个 Claude 会话
- Workspace 在地图上显示为带 "WS" 标记的岛

**删除 Workspace：** 右键 → "Delete Workspace"（需要确认），会把 Workspace 目录和所有会话一起移到废纸篓。

### 8. 自动更新

Session Cove 每 4 小时检查一次 GitHub 是否有新版本：
- 发现新版本 → 系统通知 + 设置页面显示提示
- 打开 **设置 → 关于** → 点"立即更新"
- 自动下载 → 安装 → 重启，全程无需手动操作

## 设置说明

打开方式：右键章鱼 → "Settings..."

| 标签页 | 能设置什么 |
|--------|-----------|
| **通用** | 显示模式、开机自启、音效开关和音量、通知偏好、首选终端 |
| **AI 框架** | 启用/禁用 Claude Code、Qoder、QoderWork、Cursor 的 Hook |
| **显示** | 字体大小、多显示器选择、刘海触发方式（悬停/点击）、宠物位置 |
| **权限** | 管理"始终允许"规则列表，可逐条关闭或全部清除 |
| **关于** | 版本信息、GitHub 链接、检查更新 |

## 数据存放位置

| 数据 | 路径 | 说明 |
|------|------|------|
| 会话记录 | `~/.claude/projects/` | Claude 自己管理的，SC 只读取 |
| SC 配置 | `~/.session-cove/` | 自定义名称、Workspace、Hook 脚本 |
| 权限规则 | `~/.session-cove/allowlist.json` | "始终允许"的规则 |
| Workspace | `~/.session-cove/workspaces.json` | Workspace 定义 |

更新 app 不会影响这些数据。卸载时这些文件会保留。

## 常见问题

**Q: 打不开 app，提示"无法验证开发者"**

A: 系统设置 → 隐私与安全性 → 找到 Session Cove → 点"仍要打开"。或终端执行：
```bash
xattr -cr /Applications/Session\ Cove.app
```

**Q: 恢复会话时终端没反应**

A: 确认已授予 Session Cove 自动化权限（系统设置 → 隐私与安全性 → 自动化）。

**Q: 审批弹窗没出现**

A: 重启当前的 Claude Code 会话（hooks 在会话启动时加载，已经运行的会话需要重启才生效）。

**Q: 想完全卸载**

A:
```bash
rm -rf /Applications/Session\ Cove.app
rm -rf ~/.session-cove
# 恢复 Claude 设置（如果想移除 hooks）
cp ~/.claude/settings.session-cove-backup.json ~/.claude/settings.json
```
